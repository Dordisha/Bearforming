# Bearforming branding

Approved direction: funny strong brown bear based on Dorian's features, black rectangular glasses, full beard, gray-brown cap with an original Bearforming paw patch, red Albanian double-headed eagle T-shirt, evergreen forest badge and cream/green wordmark.

The approved PNG is bundled in App/Resources/Assets.xcassets/BearformingLogo.imageset and displayed on Today. It is logo artwork, not a validated App Store icon set. Final icon crops, small-size legibility and accessibility still need device review. Bass Pro Shops branding has been removed from the approved version.
